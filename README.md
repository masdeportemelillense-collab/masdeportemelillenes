# Más Deporte Melillense

Resultados en directo de los equipos de Melilla · temporada 2026-27.

**Web publicada:** [masdeportemelillenes.vercel.app](https://masdeportemelillenes.vercel.app)

Fútbol, baloncesto, voleibol, balonmano, fútbol sala y BSR. Cada equipo tiene resultados, calendario y clasificación.

## Código

Este repositorio ya está público y conectado a Vercel. No uses GitHub Pages: la web necesita Vercel.

## Publicar o actualizar

Si Vercel sigue conectado, cada cambio en `main` se publica solo.

Para conectar de nuevo:

1. Entra en [vercel.com](https://vercel.com) con GitHub.
2. **Add New → Project** e importa `masdeportemelillenes`.
3. Build command: `npm run build`.
4. **Deploy**.

La URL pública será `https://masdeportemelillenes.vercel.app`.
